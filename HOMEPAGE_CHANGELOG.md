# Homepage & Student Registration Summary

Purpose
- Short summary of the UI changes made so someone else can review and give feedback.

What I built
- A modern homepage / landing page for the Wayamba University Postgraduate Portal.
  - Clean hero with gradient blobs and modern CTAs.
  - Two clear panels: Login (buttons) and Register (links to forms).
  - Removed dashboard-style role cards and post-login proposal access from the homepage (dashboard pages will be implemented later).
- Added a dedicated Student Registration route that renders the existing multi-step application form.
  - Route: `/student-registration` (file: `src/app/student-registration/page.tsx`)

Key files changed/added
- `src/app/page.tsx` — replaced the old landing page with a modern hero, login/register panels, and a neutral portal note.
- `src/app/student-registration/page.tsx` — NEW page that renders the existing `MultiStepForm` as the student registration flow.
- The multi-step form component remains in `src/components/form/MultiStepForm.tsx` and was not changed.

Why this matters
- Keeps the homepage focused on entry points (login / register) while deferring dashboard complexity.
- Avoids client-server boundary errors by ensuring Server Components do not pass event handlers to Client Components (fixed in `student-registration` page).

How to run locally
1. From project root (`pg-project`) install deps (already done earlier):

```bash

```

2. Start dev server:

```bash
npm run dev
```

3. Open the app in a browser:

http://localhost:3000
